A single safety warning label that should come printed on every human being, written to `/output/entry.txt` by `main.py`. This human says "I'm fine" while visibly on fire; keep water and a second opinion within reach.

## Run it

```sh
python3 main.py
```

## The warning label

> WARNING: This human says 'I'm fine' while visibly on fire. Keep water and a second opinion within reach.
